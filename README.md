# HorusLabs Inventory

Bienvenue dans **HorusLabs Inventory**, une plateforme de suivi des équipements pensée pour les environnements techniques et collaboratifs.  
Ce projet est né d’un besoin concret : gérer efficacement les ressources, tout en offrant une interface intuitive et élégante.

---

## Fonctionnalités principales

-  **Recherche et filtres dynamiques** : par nom, catégorie, état, utilisabilité…
-  **Vue détaillée** : accès rapide aux informations complètes d’un équipement
-  **Bouton de réinitialisation** : pour repartir sur une vue globale

##  Technologies utilisées

- **Python 3**
- **Django**
- **HTML / CSS**
- **PostgreSQL**
- **Git & GitHub** pour le versionnement
